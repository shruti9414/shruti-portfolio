STEP-BY-STEP COMMANDS
================================================================================

STEP 1️⃣  - CREATE PROJECT
─────────────────────────────────────────────────────────────────────────────
Open Terminal/PowerShell and run:

  npx create-next-app@latest shruti-3d-portfolio --typescript --tailwind --app

  (Select:
   - ESLint: Yes
   - Use `src/` directory: No
   - Use import aliases: Yes
  )

Then navigate to project:
  cd shruti-3d-portfolio


STEP 2️⃣  - INSTALL PACKAGES
─────────────────────────────────────────────────────────────────────────────
Run:
  npm install three framer-motion lucide-react swiper


STEP 3️⃣  - COPY FILES
─────────────────────────────────────────────────────────────────────────────
Copy these files from the scratchpad to your project:

TO app/ FOLDER:
  ✓ page.jsx
  ✓ layout.jsx
  ✓ globals.css
  ✓ Hero3DSection.jsx
  ✓ ProjectsSection.jsx
  ✓ SkillsSection.jsx
  ✓ TestimonialsSection.jsx

TO ROOT FOLDER:
  ✓ package.json (merge dependencies)
  ✓ next.config.js
  ✓ tailwind.config.js
  ✓ postcss.config.js
  ✓ portfolioData.js


STEP 4️⃣  - ADD YOUR PHOTOS
─────────────────────────────────────────────────────────────────────────────
Create public/ folder in your project (if not exists) and add:

  public/
    ├── photo-with-bg.jpg      (Your photo with background)
    └── photo-no-bg.png        (Your photo without background)

💡 TIP: If you only have one photo, use it for both paths in page.jsx


STEP 5️⃣  - UPDATE CONTENT
─────────────────────────────────────────────────────────────────────────────
Open portfolioData.js and update:

  • projectsData - Your projects with metrics
  • testimonialsData - LinkedIn recommendations
  • experienceData - Your work experience


STEP 6️⃣  - RUN DEVELOPMENT SERVER
─────────────────────────────────────────────────────────────────────────────
Run:
  npm run dev

Then open:
  http://localhost:3000

You should see your beautiful 3D portfolio! 🎉


STEP 7️⃣  - DEPLOY TO VERCEL
─────────────────────────────────────────────────────────────────────────────
Create git repo:
  git init
  git add .
  git commit -m "Initial commit"

Push to GitHub:
  git remote add origin https://github.com/YOUR_USERNAME/shruti-3d-portfolio.git
  git push -u origin main

Then:
  1. Go to vercel.com
  2. Click "Import Project"
  3. Select your GitHub repo
  4. Click Deploy! ✨

CUSTOMIZATION QUICK COMMANDS

CHANGE ACCENT COLOR (Cyan → Your Color):
─────────────────────────────────────────────────────────────────────────────
Edit tailwind.config.js:

  cyan: {
    400: '#YOUR_COLOR_HERE',   // Change these
    500: '#YOUR_COLOR_HERE',   // to your hex colors
    600: '#YOUR_COLOR_HERE',
  }

Popular colors:
  • Purple: #a78bfa
  • Blue: #3b82f6
  • Green: #10b981
  • Pink: #ec4899


CHANGE PHOTO PATHS:
─────────────────────────────────────────────────────────────────────────────
In page.jsx, find this and update:

  const bgPhotoPath = '/photo-with-bg.jpg';
  const noBgPhotoPath = '/photo-no-bg.png';


RUN PRODUCTION BUILD:
─────────────────────────────────────────────────────────────────────────────
  npm run build
  npm start


FIX PORT 3000 ALREADY IN USE:
─────────────────────────────────────────────────────────────────────────────
Windows:
  netstat -ano | findstr :3000
  taskkill /PID <PID> /F

Mac/Linux:
  lsof -i :3000
  kill -9 <PID>

Or use different port:
  npm run dev -- -p 3001

================================================================================
TROUBLESHOOTING
================================================================================

❌ Problem: 3D canvas is blank
✅ Solution:
   - Check browser console (F12 → Console)
   - Verify WebGL support: https://get.webgl.org/
   - Try different browser

❌ Problem: Photos not showing
✅ Solution:
   - Verify files in public/ folder
   - Check paths in page.jsx
   - Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

❌ Problem: Build errors
✅ Solution:
   - rm -rf .next node_modules
   - npm install
   - npm run build

❌ Problem: Animations stuttering
✅ Solution:
   - Reduce particle count in Hero3DSection.jsx
   - Check CPU usage
   - Close other apps
